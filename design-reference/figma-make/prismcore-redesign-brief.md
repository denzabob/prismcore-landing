# PRISMCORE.RU — PREMIUM LANDING PAGE REDESIGN

## 1. Задача

Создай полный редизайн главной страницы существующего российского SaaS-сервиса **Призма / PrismCore**.

Домен: **prismcore.ru**

Язык интерфейса и всего контента: **русский**.

Это не новый вымышленный продукт. PrismCore уже существует и находится на стадии MVP.

Необходимо создать современный, дорогой, профессиональный дизайн главной страницы, который соответствует текущему состоянию продукта и одновременно позволяет платформе значительно расширяться в будущем.

Главная задача — не просто сделать красивый SaaS landing page, а создать визуальный фундамент бренда **Призма как профессиональной программной платформы для экспертной деятельности**.

---

# 2. Что такое Призма

**Призма — профессиональная платформа для работы эксперта.**

Она создаётся как единая рабочая среда, объединяющая специализированные инструменты для различных этапов экспертной работы.

На текущем этапе доступны два продуктовых модуля:

### 1. Экспертная смета

Основной и наиболее зрелый модуль продукта.

Используется для расчёта стоимости устранения недостатков, работы с материалами, работами, рыночными ценами, источниками и формирования профессионального результата расчёта.

### 2. Индексы цен

Новый модуль, доступный в MVP.

Предназначен для работы с официальными статистическими индексами, исследования динамики цен и пересчёта стоимости между различными периодами.

Используются данные Росстата, в том числе CPI и PPI.

# 3. Архитектура бренда

Очень важно:

**НЕ позиционируй Призму только как программу для составления смет.**

Также:

**НЕ позиционируй Призму как сервис исключительно для работы с индексами Росстата.**

Правильная архитектура:

PRISMCORE / ПРИЗМА
↓
Профессиональная платформа для работы эксперта
↓
Набор специализированных модулей
↓
Экспертная смета / Индексы / будущие профессиональные инструменты

Сейчас главным продуктом является **Экспертная смета**, поэтому она должна получать основной визуальный и информационный акцент.

Индексы являются полноценным вторым модулем.

Архитектура дизайна должна позволять в дальнейшем добавлять новые модули без полного редизайна сайта.

Не показывай несуществующие функции как доступные.
